# Component 1: `kotlin-kiosk-wrapper`

Este componente contiene el proyecto nativo Android en Kotlin (Android 4.4 a 14+) para envolver la interfaz del Verificador de Precios en un WebView inmersivo Kiosk.

## Estructura
```
kotlin-kiosk-wrapper/
├── app/
│   ├── src/main/
│   │   ├── java/com/gsigma/kiosk/
│   │   │   ├── MainActivity.kt
│   │   │   └── ConfigActivity.kt
│   │   └── AndroidManifest.xml
│   └── build.gradle
└── build.gradle
```
